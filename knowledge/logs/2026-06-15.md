## 2. 公式ドキュメント新情報（best-practices / sub-agents / hooks / memory）

### 2.1 /sandbox — OS レベル分離（未記録）

公式ドキュメントに `/sandbox` コマンドが明記された。コミュニティデータによると**パーミッションプロンプトを約84%削減**。

- ファイルシステムとネットワークアクセスを OS レベルで制限
- 自動承認できる範囲を広げつつ安全性を維持
- `claude --permission-mode auto` より更に強固なサンドボックス

### 2.2 /loop・/schedule — 定期タスク（未記録）

| コマンド | 実行場所 | 最大間隔 |
|---------|---------|---------|
| `/loop` | ローカル | 7日間 |
| `/schedule` | Anthropic クラウド | 未定（クラウドベース） |

Ralph Wiggum プラグインも長時間自律タスク向けに推奨されている（コミュニティ）。

### 2.3 `<important if="...">` タグ — ドメイン特化ルール（未記録）

CLAUDE.md 内でドメイン特化ルールを無視させないためのタグ。

```markdown
<!-- CLAUDE.md -->
<important if="working on auth code">
すべての認証関連変更にはセキュリティレビューが必要。
</important>
```

### 2.4 コンテキスト劣化の具体的しきい値（未記録）

- **300-400k トークン**: コンテキストウィンドウが詰まり始め劣化開始
- **40% 使用量**: "dumb zone"（経験豊富なユーザーは 30% 以下を維持）
- **85%+**: 幻覚が増加
- **90%+**: レスポンスが不規則になる

### 2.5 サブエージェント5段階ネスト（v2.1.172+）

サブエージェントが自分のサブエージェントをスポーンできるようになった（最大5段階）。

```
メインセッション
  └── サブエージェント L1（orchestrator）
        └── サブエージェント L2（researcher）
              └── サブエージェント L3（analyzer）
                    └── サブエージェント L4（validator）
                          └── サブエージェント L5（reporter）
```

### 2.6 `context: fork` スキルフィールド（未記録）

スキルを独立した分岐サブエージェントで実行するフィールド。

```markdown
---
name: heavy-analysis
description: 大規模コード解析
context: fork
---
```

### 2.7 `CLAUDE_AGENT_SDK_DISABLE_BUILTIN_AGENTS=1`（未記録）

非対話型モードまたは Agent SDK でビルトインサブエージェントを完全無効化し、カスタム定義のみを使用する。

```bash
CLAUDE_AGENT_SDK_DISABLE_BUILTIN_AGENTS=1 claude -p "analyze"
```

### 2.8 プラグインサブエージェントのスコープ識別子（詳細化）

プラグインの `agents/` ディレクトリ内のサブディレクトリが識別子の一部になる。

| ファイルパス | 識別子 |
|------------|------|
| `agents/review/security.md`（プラグイン `my-plugin`） | `my-plugin:review:security` |
| `agents/research.md`（プラグイン `my-plugin`） | `my-plugin:research` |

### 2.9 CLAUDE.md のコンパクト後の動作（明確化）

- **プロジェクトルート CLAUDE.md**: `/compact` 後に自動再読み込み・再注入される
- **サブディレクトリの CLAUDE.md**: コンパクト後は自動再注入されない（次にそのディレクトリのファイルを読んだときに再ロード）
- 重要なルールはプロジェクトルートの CLAUDE.md に置くことが推奨

### 2.10 /memory コマンドの詳細（確認・補完）

```
/memory コマンド
├── CLAUDE.md / CLAUDE.local.md / rules ファイル一覧
├── Auto Memory のオン/オフトグル
└── Auto Memory フォルダへのリンク（開いて編集可能）
```

Claude に「〇〇を覚えておいて」と頼むと Auto Memory に保存。「CLAUDE.md に追加して」と頼むと CLAUDE.md に追記。
