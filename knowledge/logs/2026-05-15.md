### v2.1.139（大型リリース）

- フック `args: string[]`（exec形式）追加: シェルを介さず直接コマンド起動
- フック `continueOnBlock` オプション追加（PostToolUse）: ブロック理由を Claude にフィードバックしてターン継続

## 公式ベストプラクティス（最新）

### コンテキスト管理（最重要）
- コンテキストウィンドウの管理が最重要制約
- `/clear` で無関係タスク間をリセット
- サブエージェントを調査に使用してメインコンテキストを節約
- CLAUDE.md は200行以下に保つ（長すぎると指示が無視される）

### 推奨ワークフロー
1. **Explore（Plan Mode）** → ファイル読み込み・質問、変更なし
2. **Plan** → 詳細な実装計画作成（`Ctrl+G` でエディタ編集）
3. **Implement** → コーディング+テスト検証
4. **Commit** → コミット＆PR作成

### サブエージェント活用
- 調査には「use subagents to investigate X」を使用
- Writer/Reviewer パターン（2つのセッションで実装＋レビュー）
- Fan-out パターン（`claude -p` をループでファイル単位に並列実行）

### Auto Mode
```bash
claude --permission-mode auto -p "fix all lint errors"
```

## メモリシステム（最新）

### CLAUDE.md ヒエラルキー
1. マネージドポリシー（組織全体）
2. `~/.claude/CLAUDE.md`（ユーザー全体）
3. `./CLAUDE.md` or `./.claude/CLAUDE.md`（プロジェクト共有）
4. `./CLAUDE.local.md`（個人・gitignore推奨）

### Auto Memory
- 保存先: `~/.claude/projects/<project>/memory/MEMORY.md`
- 先頭200行または25KBをセッション開始時にロード
- `autoMemoryEnabled: false` で無効化
- `/memory` コマンドで閲覧・編集

### .claude/rules/ ディレクトリ
- パススコープルール対応（frontmatterの `paths` フィールド）
- シンボリックリンクで共有ルールを複数プロジェクトに展開可能
- ユーザーレベルルール: `~/.claude/rules/`

### 新設定
- `claudeMdExcludes`: 特定のCLAUDE.mdファイルを除外
- `CLAUDE_CODE_NEW_INIT=1`: インタラクティブな `/init` フロー

## フック機能（最新）

### フックの種類（5種）
1. `command`: シェルコマンド実行
2. `http`: HTTPエンドポイントへのPOST
3. `mcp_tool`: MCPサーバーのツール呼び出し
4. `prompt`: Claudeモデルへの判断委託
5. `agent`: サブエージェント起動（実験的）

### 主要イベント
- `SessionStart`, `UserPromptSubmit`, `PreToolUse`, `PostToolUse`, `Stop`, `SessionEnd`
- 新: `InstructionsLoaded`（CLAUDE.md読み込み監視）
- 新: `UserPromptExpansion`（スラッシュコマンド展開制御）

### 新機能
- `terminalSequence`: デスクトップ通知対応（v2.1.141+）
- `args: string[]`: exec形式（シェルなし直接起動）（v2.1.139+）
- `continueOnBlock`: PostToolUseでのブロック後継続（v2.1.139+）
