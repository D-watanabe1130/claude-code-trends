## 詳細解説

### 1. `autoCompactWindow` フロントマターフィールド（v2.1.296）

サブエージェントごとに、自動圧縮（autocompact）が発火するトークン数の閾値を指定できる新フィールド。

```yaml
---
name: my-agent
autoCompactWindow: 200000
---
```

- 設定範囲: 100,000〜1,000,000 トークン
- **重要**: `"200k"` のような省略記法は誤読されるため、**整数値で記述すること**
- セッション全体への環境変数による上書き: `CLAUDE_CODE_AUTO_COMPACT_WINDOW`
- 長時間稼働サブエージェントや大規模コードベース操作のサブエージェントで特に有効

### 2. `effort` per-invocation パラメーター（v2.1.292）

Agent ツール呼び出し時に `effort` を per-invocation パラメーターとして指定できるようになった。

- 非フォーク型サブエージェントに対してフロントマターの `effort` 設定を上書き可能
- バージョン **v2.1.292** 以降が必須
- これにより同一サブエージェント定義を複数エフォートレベルで再利用できる

### 3. `CLAUDE_CODE_AUTO_COMPACT_WINDOW` 環境変数

新フィールド `autoCompactWindow` を環境変数で一括設定する際に使用。settings.json の `env` ブロックに記述することでセッション全体のサブエージェントに適用可能。

### 4. AGENTS.md プラグイン ID の変更（v2.1.285）

AGENTS.md 読み込みを担うビルトインプラグインの ID が変更された:

- 旧: `agents-md@builtin`
- 新: **`cc-plugin-agents-md@builtin`**

v2.1.285 以降では両方の ID が認識されるため後方互換性あり。settings.json でプラグイン設定を記述している場合は新 ID への移行を推奨。

```json
{
  "pluginConfigs": {
    "cc-plugin-agents-md@builtin": {
      "options": { "instructionFiles": "claude-md-and-agents-md" }
    }
  }
}
```

### 5. `permissionDecision: "defer"` オプション（フック）

`PreToolUse` フックの JSON 出力で `permissionDecision` に指定できる選択肢が確認された:

- `allow` / `deny` / `ask` / **`defer`**

前回レポートで `skip` として記録していた第3オプションが `defer` として整理。`ask`（Claude に確認を委ねる）と `defer`（処理を先送り）は異なる動作を示す。

### 6. `bypassPermissions` 条件の記録訂正

前回レポートの記述「メインセッションが `bypassPermissions` で動作している場合のみ有効」は誤り。

正しくは: **メインセッションが `default`/`dontAsk`/`plan` モードで動作している場合にサブエージェントで `bypassPermissions` が設定可能**（v2.1.267+）。

### 7. 総フックイベント数: 33種（ドキュメント明示）

公式ドキュメントで総フックイベント数が **33** と明示された。カテゴリ別内訳:

| カテゴリ | イベント一覧 |
|---------|------------|
| Session | SessionStart / Setup / SessionEnd |
| Per turn | UserPromptSubmit / UserPromptExpansion / Stop / StopFailure |
| Tool loop | PreToolUse / PermissionRequest / PermissionDenied / PostToolUse / PostToolUseFailure / PostToolBatch |
| Subagents & tasks | SubagentStart / SubagentStop / TaskCreated / TaskCompleted / TeammateIdle |
| Context & config | InstructionsLoaded / ConfigChange / PreCompact / PostCompact |
| Environment | CwdChanged / DirectoryAdded / FileChanged / WorktreeCreate / WorktreeRemove |
| Models | PreModelSwitch / PostModelSwitch |
| MCP | Elicitation / ElicitationResult |
| Other | Notification / MessageDisplay |

### 8. `claude --debug` でunknownフィールドのログ出力（v2.1.296）

`claude --debug` 実行時、サブエージェントフロントマターに認識されないフィールドがある場合に `does not recognize or apply` メッセージがログに出力されるようになった。フロントマターのデバッグに活用可能。
