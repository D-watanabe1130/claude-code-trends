## 今週のホットトピック（2026-09-21）

### 1. v2.1.277+: AGENTS.md ネイティブサポート【今週の最大トピック】

Claude Code が `AGENTS.md` をネイティブに直接読み込めるようになった（v2.1.277+ 必須）。これは **他のコーディングエージェント（GitHub Copilot・Cursor 等）と同じリポジトリを共有するチームにとって重大な変更**で、従来必要だった `@AGENTS.md` インポートや symlink によるワークアラウンドが不要になった。

**「Project instructions」新設定（`/config` パネル）:**

| 設定値 | 動作 |
|--------|------|
| `claude-md-or-agents-md`（デフォルト）| `CLAUDE.md` があれば読む。なければ `AGENTS.md` を読む |
| `claude-md-and-agents-md` | `CLAUDE.md` と `AGENTS.md` の両方を読む |
| `claude-md` | `CLAUDE.md` のみ読む |
| `managed-only` | マネージド CLAUDE.md と Auto Memory のみ。project/local/user CLAUDE.md・.claude/rules/・AGENTS.md は全てスキップ |

`/config` パネルではなく設定ファイルから制御する場合は `pluginConfigs` キーを使用：

```json
{
  "pluginConfigs": {
    "agents-md@builtin": {
      "options": { "instructionFiles": "claude-md-and-agents-md" }
    }
  }
}
```

**AGENTS.md 読み込み時の制限事項（CLAUDE.md との違い）：**
- `/memory` や `/context` の **Memory files リストに表示されない**（直接読み込み時）
- `InstructionsLoaded` フックが**発火しない**（`CLAUDE.md` がインポートした場合は発火）
- `--add-dir` + `CLAUDE_CODE_ADDITIONAL_DIRECTORIES_CLAUDE_MD=1` のとき追加ディレクトリの `AGENTS.md` は読み込まれない
- 外部パスへの `@path` インポートは承認ダイアログなしで読み込む

**読み込まれないファイル:** `AGENTS.local.md`・`AGENTS.override.md`・`.agents/` ディレクトリ配下のファイル

**v2.1.277+ が使えないケース:**
- Amazon Bedrock / Vertex 等サードパーティプロバイダー経由のセッション
- テレメトリ無効セッション
- インストール/アップグレード直後の最初のセッション（次のセッションから有効）
- `disableAllHooks: true` / `allowManagedHooksOnly: true` 設定時
- `agents-md` ビルトインプラグインを `/plugin` で無効化した場合

これらのケースでは従来通り `CLAUDE.md` から `@AGENTS.md` でインポートすることで対応可能。

### 2. v2.1.271+: `omitClaudeMd` サブエージェントフロントマターフィールド

サブエージェントのフロントマターに `omitClaudeMd: true` を設定すると、そのサブエージェント起動時に **user/project/local スコープの CLAUDE.md ファイルを全てスキップ**できるようになった。

```yaml
---
name: isolated-analyzer
description: CLAUDE.md を読み込まず分離された状態で動作するアナライザー
omitClaudeMd: true
---
```

用途：
- プロジェクトの CLAUDE.md の影響を受けずに純粋な分析を行いたいサブエージェント
- 異なる規約セットで動作させたいサブエージェント
- パフォーマンス優先でコンテキスト節約したいサブエージェント
