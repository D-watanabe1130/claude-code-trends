## 今週の最大トピック：サブエージェントの大幅進化

前回調査時点でサブエージェントの基本仕様（description・tools・model）は把握していたが、今回の公式ドキュメント取得でフロントマターフィールドが大幅に拡張されていることが判明した。

### 新フロントマターフィールド一覧

| フィールド | 説明 |
|-----------|------|
| `disallowedTools` | 拒否するツールのdenylist（既存の `tools` はallowlist） |
| `permissionMode` | サブエージェントの権限モード（default/acceptEdits/auto/dontAsk/bypassPermissions/plan） |
| `maxTurns` | 最大ターン数上限 |
| `skills` | 起動時にコンテキストへプリロードするスキルリスト |
| `mcpServers` | サブエージェント専用MCPサーバー（インライン定義またはサーバー名参照） |
| `memory` | 永続メモリスコープ: `user` / `project` / `local` |
| `background` | 常にバックグラウンド実行するかどうか |
| `effort` | 努力レベル（low/medium/high/xhigh/max）のオーバーライド |
| `isolation` | `worktree` で独立gitワークツリー内で実行 |
| `color` | UIでの表示色（red/blue/green/yellow/purple/orange/pink/cyan） |
| `initialPrompt` | `--agent` フラグでメインセッションとして起動時の初期プロンプト |

### サブエージェントの永続メモリ詳細（memory フィールド）

```yaml
---
name: code-reviewer
memory: user   # または project / local
---
```

| スコープ | 保存先 | 用途 |
|---------|-------|------|
| `user` | `~/.claude/agent-memory/<name>/` | 全プロジェクト横断で知識を蓄積 |
| `project` | `.claude/agent-memory/<name>/` | プロジェクト固有（バージョン管理で共有可） |
| `local` | `.claude/agent-memory-local/<name>/` | プロジェクト固有（バージョン管理外） |

起動時に `MEMORY.md` の先頭200行または25KBをコンテキストへ自動注入。

## /agents コマンド（新機能）

`/agents` コマンドで新しいTUIインターフェースが提供されている。

- **Runningタブ**: 実行中サブエージェントの一覧・停止
- **Libraryタブ**: 全サブエージェントの確認・新規作成・編集・削除
- サブエージェントの作成方法: インタラクティブ選択 or Claudeによる生成
- スコープ選択（Personal/Project）、ツール・モデル・カラー・メモリ設定を一括設定
- 作成後は再起動なしで即時利用可能（ファイル直接編集の場合は再起動が必要）

## フォークモード（実験的機能）

```bash
CLAUDE_CODE_FORK_SUBAGENT=1 claude
```

フォークは**現在の会話履歴を丸ごと継承するサブエージェント**。通常のサブエージェントが新鮮なコンテキストで開始するのと異なり、親セッションのシステムプロンプト・ツール・モデル・会話履歴をそのまま引き継ぐ。

- **`/fork <指示>`** コマンドで起動
- 並列実験（複数アプローチを同時に試す）や、コンテキストの再説明が不要な場合に有効
- フォークの最初のリクエストは親セッションのプロンプトキャッシュを再利用（安価）
- フォークが有効な場合、サブエージェント生成が全てバックグラウンドで実行

## サブエージェント呼び出し方法の整理

### 3段階のエスカレーション

1. **自然言語**: 「Use the code-reviewer subagent to...」（Claudeが委任判断）
2. **@-メンション**: `@"code-reviewer (agent)"` で特定サブエージェントを保証実行
3. **セッション全体**: `claude --agent code-reviewer` でセッション全体をそのサブエージェントとして動作

```bash
# CLI定義（その場限り、ファイル不要）
claude --agents '{"code-reviewer": {"description": "...", "prompt": "...", "tools": ["Read"], "model": "sonnet"}}'

# セッション全体をそのエージェントとして動作
claude --agent code-reviewer

# プロジェクトのデフォルトエージェントを設定
# .claude/settings.json: {"agent": "code-reviewer"}
```

### Agent(agent_type) 構文

特定のサブエージェントのみ生成できるエージェントを定義：

```yaml
---
name: coordinator
tools: Agent(worker, researcher), Read, Bash
---
```

`Agent(...)` なし → サブエージェント生成不可。`Agent` のみ → 全サブエージェント生成可。

## サブエージェントのスコープと優先順位

| 場所 | スコープ | 優先度 |
|------|---------|-------|
| マネージド設定 | 組織全体 | 1（最高） |
| `--agents` CLIフラグ | 現在セッション | 2 |
| `.claude/agents/` | 現プロジェクト | 3 |
| `~/.claude/agents/` | 全プロジェクト | 4 |
| プラグインの `agents/` | プラグイン有効時 | 5（最低） |

同名のサブエージェントが複数ある場合、優先度が高いものが有効。プラグインは `my-plugin:review:security` 形式のスコープ付き識別子を使用。

## フックシステム：新規判明事項

### 5種類のフックタイプ（確定）

| タイプ | 説明 |
|-------|------|
| `command` | シェルコマンド実行 |
| `http` | HTTP POSTリクエスト |
| `mcp_tool` | MCPサーバーのツール呼び出し |
| `prompt` | Claudeへのプロンプト評価（yes/no判断） |
| `agent` | サブエージェント生成（実験的） |

### 新確認イベント（計30種）

前回未確認の新イベント：

- `TeammateIdle` - エージェントチームのチームメイトがアイドル状態に
- `StopFailure` - APIエラーによるターン終了
- `PostToolUseFailure` - ツール失敗後
- `UserPromptExpansion` - スラッシュコマンドの展開
- `InstructionsLoaded` - CLAUDE.mdや設定ファイルのロード時
- `CwdChanged` - 作業ディレクトリ変更時
- `ConfigChange` - 設定ファイル変更時（`user_settings`, `policy_settings`）
- `ElicitationResult` - ユーザーがMCP elicitationに回答した時
- `Setup` - `--init-only`, `--init`, `--maintenance` フラグでの初回セットアップ

### 新フックフィールド

```json
{
  "type": "command",
  "command": "check.sh",
  "if": "Bash(git *)",        // 新: パーミッションルールフィルター
  "shell": "bash",             // 新: シェル指定
  "timeout": 600
}
```

### CLAUDE_ENV_FILE（新）

SessionStart、Setup、CwdChanged、FileChanged フックで利用可能。Bash 後続コマンドに環境変数を永続させる：

```bash
#!/bin/bash
if [ -n "$CLAUDE_ENV_FILE" ]; then
  echo 'export NODE_ENV=production' >> "$CLAUDE_ENV_FILE"
fi
```

### watchPaths（新）

SessionStart フックの出力で指定することで FileChanged イベントを有効化：

```json
{
  "hookSpecificOutput": {
    "hookEventName": "SessionStart",
    "watchPaths": ["/project/.envrc", "/project/.env"]
  }
}
```

## CLAUDE.md・メモリ：新規判明事項

### claudeMdExcludes（新）

モノレポで不要な CLAUDE.md をスキップ。全設定レイヤーで配列がマージされる：

```json
{
  "claudeMdExcludes": [
    "**/monorepo/CLAUDE.md",
    "/home/user/monorepo/other-team/.claude/rules/**"
  ]
}
```

### ユーザーレベルルール（新）

`~/.claude/rules/` でプロジェクト横断のパーソナルルールを定義：

```
~/.claude/rules/
├── preferences.md
└── workflows.md
```

プロジェクトルールより先にロード（プロジェクトルールが優先）。

### .claude/rules/ のシンボリックリンク対応（新）

複数プロジェクトで共通ルールを共有：

```bash
ln -s ~/shared-claude-rules .claude/rules/shared
```

### InstructionsLoaded フック（新）

どの instruction ファイルがいつロードされたかをデバッグ：

```json
{
  "hooks": {
    "InstructionsLoaded": [
      { "hooks": [{ "type": "command", "command": "log-instructions.sh" }] }
    ]
  }
}
```

## ベストプラクティス：新規追加事項

### プラグイン機能（新）

```
/plugin  # マーケットプレイスを開く
```

スキル・フック・サブエージェント・MCPサーバーを1つのインストール単位にバンドル。typed言語向けの**コードインテリジェンスプラグイン**（シンボルナビゲーション・エラー検出）が存在する。

### Agent Teams（新・実験的）

```bash
CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1
```

複数セッションの自動協調を行う。チームリード・メッセージング・共有タスクを管理。単純なサブエージェント並列では対応できない大規模タスクに対応。`SendMessage` ツールでエージェント間通信が可能。

### /rewind の新オプション

- **Summarize from here**: 選択メッセージ以降を要約（それ以前のコンテキストを保持）
- **Summarize up to here**: 選択メッセージより前を要約（直近のコンテキストを保持）

### /compact の強化

```
/compact Focus on the API changes
```

圧縮時に保持すべき内容を指示可能。

### セッション再開フラグ

```bash
claude --continue   # 最新セッションを再開
claude --resume     # セッション一覧から選択
```

### Worktrees（並列実行の基盤）

独立したgitチェックアウトで複数Claudeセッションを安全に並列実行。編集の衝突を回避。

### コンテキストウィンドウ可視化ページ

新ドキュメント `/en/context-window` でスタートアップ時の読み込み内容とコストを可視化。サブエージェントが別ウィンドウで作業する様子をインタラクティブに確認可能。

### Chrome拡張機能によるUI自動検証

Claude in Chrome拡張機能でブラウザの新タブを開き、UIを実際にテストして自動反復。
