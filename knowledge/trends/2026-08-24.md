## 今週のホットトピック（2026-08-24）

### 1. バージョン v2.1.234+ 確認・`CLAUDE_CODE_PROJECT_DIR_NAME` 環境変数

`CLAUDE_CODE_PROJECT_DIR_NAME` 環境変数が新たに文書化された。`CLAUDE_CONFIG_DIR` と並べて設定すると、起動するリポジトリに関わらず常に同じプロジェクトディレクトリ名を使用する。複数リポジトリで同じ設定ディレクトリを使用する場合に **Auto Memory を共有できる**という実用的な新機能。

```bash
# 複数リポジトリ間でAuto Memoryを共有
CLAUDE_CONFIG_DIR=~/.claude-shared CLAUDE_CODE_PROJECT_DIR_NAME=my-project claude
```

これにより `<config dir>/projects/my-project/memory/` に Auto Memory が保存され、この設定で起動した全リポジトリで共有される。v2.1.234+ 必須。

### 2. 新規フックイベント3件

前回の知識ベースに記録されていなかった以下の3イベントが公式ドキュメントで確認された:

| イベント | 発火タイミング |
|---------|-------------|
| `TeammateIdle` | Agent team のチームメイトがアイドル状態になったとき |
| `DirectoryAdded` | セッション途中でディレクトリが追加されたとき |
| `UserPromptExpansion` | コマンドがプロンプトに展開されたとき（`/skill` 呼び出し等） |

特に `TeammateIdle` は Agent teams との連携フックで、チームメイトが次の指示を待つタイミングでコーディネーター側から処理を引き継ぐパターンに使える。

### 3. `/batch` コマンド（Fan-out の新標準）

```text
/batch <instruction>
```

git リポジトリ内でこのコマンドを実行すると、Claude が変更を **5〜30 個のサブエージェント**に自動分割し、各サブエージェントが独立したワークツリーで作業してプルリクエストを開く。Fan-out パターンの新しい標準コマンドとして公式ベストプラクティスに明記された。従来の `for file in $(cat files.txt); do claude -p ...` ループより宣言的な代替手段。

### 4. Setup フックの詳細仕様確認

`Setup` フックイベントの matcher として `init`（`--init-only`/`--init` 時）と `maintenance`（`--maintenance` 時）が公式確認された。`--init-only` フラグとの組み合わせで一回限りのプロジェクト初期化処理を定義するユースケースが公式例として追加。
