## 今週の新規発見（前回との差分）

### 1. `/import` コマンド（v2.1.213+）

他のコーディングエージェントの設定を Claude Code に一括移行できるコマンドが公式ドキュメントで明確に言及された。

対応するインポート元:
- **Cursor**: `.cursor/rules/` または `.cursorrules`
- **GitHub Copilot**: `.github/copilot-instructions.md`
- **AGENTS.md**: 標準 AGENTS.md ファイル
- **Devin**: `.devin/rules/`
- **Windsurf**: `.windsurf/rules/` または `.windsurfrules`
- **Cline**: `.clinerules`

インポート対象:
- 指示ファイルを対応する `CLAUDE.md` に一時コピーとして追加
- MCP サーバー設定
- コマンド定義
- サブエージェント定義
- スキル

> これは `@AGENTS.md` インポートや symlink と異なり、ワンタイムコピーとして取り込む。継続的な同期ではない点に注意。

### 2. CLAUDE.md のブロックレベル HTML コメント除去

公式ドキュメントに明記された:

> Block-level HTML comments (`<!-- maintainer notes -->`) in CLAUDE.md files are stripped before the content is injected into Claude's context. Use them to leave notes for human maintainers without spending context tokens on them. Comments inside code blocks are preserved.

実装上の影響:
- `<!-- ... -->` 形式のコメントは Claude への注入前に削除される
- コードブロック内のコメントはそのまま保持される
- `/memory` でファイルを直接開いた場合はコメントも表示される
- 保守者向けのメモや廃止理由などを CLAUDE.md に残せるようになった

### 3. v2.1.222+: `availableModels` allowlist のブロック対応改善

サブエージェントが `model: opus` のようなファミリーエイリアスを指定し、そのファミリーが組織の `availableModels` で制限されている場合：

**以前（v2.1.221以前）**: allowlist が制限していると、継承モデル（親会話のモデル）にフォールバック  
**v2.1.222+**: allowlist が許可する最新バージョンのファミリーモデルに適切に代替（`/model` コマンドと同じ代替ルールを適用）

これにより、組織が特定バージョンのモデルのみを許可している環境でも、サブエージェントのモデル指定が意図通りに機能するようになった。

### 4. `CLAUDE_CODE_NEW_INIT=1` の詳細仕様が明記

前回から知られていたが、今週ドキュメントが拡充された：
- `/init` 実行時に CLAUDE.md だけでなく **スキル** と **フック** もセットアップするかを対話的に選択できる
- サブエージェントがコードベースを探索し、追加の質問でギャップを補完
- 承認可能な提案として提示されてから実際にファイルへの書き込みが行われる
- `AGENTS.md`、`.devin/rules/`、`.windsurf/rules/`、`.clinerules` も読み込む（`/import` 相当の読み込みが統合されている）

## 詳細技術情報（補足）

### サブエージェントモデル解決順序（最新）

1. `CLAUDE_CODE_SUBAGENT_MODEL` 環境変数
2. 呼び出し時の per-invocation `model` パラメータ（v2.1.211+: 再開時も維持）
3. フロントマターの `model` フィールド
4. メイン会話のモデル（`inherit` またはフィールド省略時）

v2.1.222+: ステップ1〜3でブロックされたファミリーエイリアスの場合、allowlist が許可する最新バージョンに代替。それも不可な場合のみステップ4にフォールバック。

### `/init` の全コーディングエージェント設定読み込み（`CLAUDE_CODE_NEW_INIT=1`）

```bash
CLAUDE_CODE_NEW_INIT=1 claude
# → /init を実行すると以下を読み込む:
# - Cursor rules (.cursor/rules/ または .cursorrules)
# - Copilot rules (.github/copilot-instructions.md)
# - AGENTS.md
# - Devin rules (.devin/rules/)
# - Windsurf rules (.windsurf/rules/ または .windsurfrules)
# - Cline rules (.clinerules)
```

### CLAUDE.md HTML コメント活用パターン

```markdown
# プロジェクト規約

<!-- 廃止予定: 2026-09-01 に削除予定の旧スタイルガイド内容 -->

## 現在のルール

- ES modules を使用する
```

上記の `<!-- ... -->` 内容はコンテキストに入らないため、保守メモをコンテキスト消費なしに記録できる。

## まとめ

今週の最大の発見は **v2.1.222+** への更新確認（前回 v2.1.218+）と、**`/import` コマンド** の公式ドキュメント詳細記載。`/import` は他のコーディングエージェント設定を Claude Code へ一括移行する機能で、チーム移行や複数エージェント並行利用環境で有用。CLAUDE.md の HTML コメント除去は小さいが実用的な改善で、保守者向けメモをコンテキストコストなしに書けるようになった。
