## 今週のホットトピック

### 1. v2.1.283: Auto Mode が全プランでデフォルトに（最重要変更）

公式ベストプラクティスドキュメントが次のように更新された:

> With Claude Code v2.1.283 or later, auto mode is the built-in starting permission mode for **interactive terminal and VS Code sessions**: a separate classifier model reviews most actions instead of you and blocks only what looks risky, such as scope escalation, unknown infrastructure, or hostile-content-driven actions. **On earlier versions, auto mode is the built-in starting permission mode only on Pro, Max, and Team plans.**

これまで Auto Mode は **Pro/Max/Team プランのみ**のデフォルトだったが、v2.1.283 から **全プラン・全インタラクティブセッション** でデフォルトになった。個人プランや Bedrock/Vertex 経由の環境でも、v2.1.283 以降は分類器モデルが危険なアクションを自動審査するようになる。

- **影響範囲**: これまでデフォルトが Manual Mode だったユーザー全員に影響
- **内容**: 分類器モデルがスコープ拡大・未知インフラ・ホスティル指示による操作をブロック
- **変更前**: Pro/Max/Team のみ Auto Mode デフォルト
- **変更後**: 全プランで Auto Mode デフォルト

### 2. v2.1.283: `/doctor prompt-audit` コマンド追加

CLAUDE.md・AGENTS.md ファイルを静的に監査する新コマンドが追加された（v2.1.283 以降必須）。

```bash
/doctor prompt-audit           # 全 CLAUDE.md/ルール/スキル/エージェントを監査
/doctor prompt-audit .claude/skills/deploy  # 特定パス配下のみ
```

**監査対象**: CLAUDE.md、CLAUDE.local.md、AGENTS.md、`.claude/` 配下のルール・スキル・コマンド・サブエージェント・出力スタイル、`~/.claude/` 配下の対応ファイル

**検出内容**:
- 古いモデル向けに書かれた指示
- 存在しないファイル・コマンドへの参照
- ファイル間の矛盾・競合する指示

監査後、変更提案が提示されるが**実際にファイルは変更されない**（ユーザーが適用を明示的に依頼するまで）。

**依存スキル**: bundled `/claude-api` スキルを経由して動作するため、`skillOverrides` や `disableBundledSkills` でこのスキルを無効にすると使用不可。

### 3. v2.1.281: AGENTS.md の Bedrock・telemetry 無効環境バグ修正

v2.1.277 で AGENTS.md ネイティブサポートが追加されたが、一部のセッション（Amazon Bedrock 経由や telemetry 無効）では v2.1.277+ があっても AGENTS.md を直接読み込めないバグがあった。**v2.1.281 でこのバグが修正**され、これらの環境でも AGENTS.md が正しく読み込まれるようになった。

**v2.1.281 以前の Bedrock/telemetry 無効環境向け回避策**（引き続き機能する）:
```markdown
<!-- CLAUDE.md -->
@AGENTS.md

## Claude Code 固有設定
```

### 4. v2.1.280: `/memory` と `/context` が AGENTS.md をリスト表示

v2.1.280 から、Claude が直接読み込んだ AGENTS.md が `/memory` と `/context` のリストに表示されるようになった。**v2.1.280 以前**は AGENTS.md の読み込みを確認するには Claude に「プロジェクト指示を教えて」と聞く必要があった。

### 5. v2.1.281: `--agents ./agents.json` JSONファイル参照対応

非インタラクティブモード（`-p`）でサブエージェント定義を JSON ファイルで参照できるようになった。

```bash
# v2.1.281+ から使用可能
claude -p --agents ./agents.json "Review my changes"
```

これまでは `--agents` フラグにインライン JSON を渡す方式のみだったが、大規模なエージェント定義をファイルで管理できるようになった。

## 公式ドキュメント新規確認情報

### サブエージェント新フィールド（正式ドキュメント化）

サブエージェントの `color` および `initialPrompt` フィールドが公式ドキュメントで初めて明示的に記載された（実装は以前から存在していた可能性あり）。

| フィールド | 型 | 値 | 用途 |
|-----------|----|----|-----|
| `color` | string | `red`, `blue`, `green`, `yellow`, `purple`, `orange`, `pink`, `cyan` | タスクリストでの表示色 |
| `initialPrompt` | string | テキスト | `--agent` フラグでセッション全体として動作するとき、自動送信される初回ユーザーターン |

```yaml
---
name: security-reviewer
description: セキュリティレビューを実施
color: red           # タスクリストで赤表示
initialPrompt: "前回のセキュリティ課題の続きから始めてください。"
---
```

`initialPrompt` は `--agent <name>` フラグでセッション全体を特定エージェントとして動作させるときのみ有効（通常のサブエージェント呼び出し時は無視される）。

### `CLAUDE_CODE_DISABLE_BACKGROUND_TASKS=1` 環境変数（公式ドキュメント化）

全サブエージェントを強制的にフォアグラウンド実行させる環境変数が公式ドキュメントに追記された。

```json
// settings.json
{
  "env": {
    "CLAUDE_CODE_DISABLE_BACKGROUND_TASKS": "1"
  }
}
```

v2.1.198+ からサブエージェントはデフォルトでバックグラウンド実行になっているが、この変数を `1` に設定すると全サブエージェントが強制的にフォアグラウンド実行になる。デバッグや、バックグラウンド化が問題となる特殊環境での利用を想定。

### AGENTS.md 詳細挙動の明文化

AGENTS.md の読み込み条件と、「CLAUDE.md を持つとカウントされるファイル」の表が公式に明文化された。

**カウントされる（AGENTS.md の代わりに読まれる）**:
- `CLAUDE.md`、`.claude/CLAUDE.md`、`CLAUDE.local.md`（作業ディレクトリまたはその上位）

**カウントされない（AGENTS.md と並行して読まれる）**:
- `~/.claude/CLAUDE.md`（ユーザー設定）
- 組織のマネージド `CLAUDE.md`
- `.claude/rules/` ファイル

**注意**: `CLAUDE.local.md` を追加すると、AGENTS.md に依存するプロジェクトで Claude が AGENTS.md を読み込まなくなる。解決策は「Project instructions」を `claude-md-and-agents-md` に変更すること。

### `/init` の新インタラクティブモード (`CLAUDE_CODE_NEW_INIT=1`)

`CLAUDE_CODE_NEW_INIT=1` 環境変数を設定して `/init` を実行すると、マルチフェーズのインタラクティブな初期化フローが有効になる:
1. どのアーティファクト（CLAUDE.md、スキル、フック）をセットアップするか選択
2. サブエージェントがコードベースを探索
3. フォローアップ質問で情報を補完
4. ファイル書き込み前に変更案をレビュー

対応する移行元ファイル: `AGENTS.md`、`.devin/rules/`、`.windsurf/rules/` または `.windsurfrules`、`.clinerules`（これらは `CLAUDE_CODE_NEW_INIT=1` 時のみ読み込み対象）
