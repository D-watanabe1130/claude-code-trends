## 今週のホットトピック

### 1. `CLAUDE_CODE_SUBAGENT_MODEL_FORCE=1`（v2.1.257+）

全サブエージェントを `CLAUDE_CODE_SUBAGENT_MODEL` 環境変数のモデルに強制する新オプション。

```json
{
  "env": {
    "CLAUDE_CODE_SUBAGENT_MODEL": "claude-haiku-4-5-20251001",
    "CLAUDE_CODE_SUBAGENT_MODEL_FORCE": "1"
  }
}
```

**モデル解決の優先順位（最優先→最低優先）:**

| 優先 | 条件 |
|------|------|
| 1（最高） | `CLAUDE_CODE_SUBAGENT_MODEL_FORCE=1` + `CLAUDE_CODE_SUBAGENT_MODEL` |
| 2 | 呼び出し時の `model` パラメータ |
| 3 | フロントマターの `model` フィールド |
| 4 | `CLAUDE_CODE_SUBAGENT_MODEL`（force なし） |
| 5 | メイン会話のモデル |

**例外（force でも上書きされない）:**
- `model: inherit` が設定されたフォークサブエージェント
- `context: fork` が設定されたスキル

**用途:** コスト管理（全サブエージェントを安価なモデルに固定）、組織ポリシー（許可モデルへの強制）。

---

### 2. `--append-subagent-system-prompt-file` フラグ（v2.1.261+）

ファイルから全サブエージェントのシステムプロンプト末尾に追記する新フラグ。`--append-subagent-system-prompt`（インライン版、v2.1.205+）のファイルベース版。

```bash
# 長い制約文書をファイルから読み込む
claude --append-subagent-system-prompt-file /path/to/constraints.txt \
  -p "investigate and fix all security vulnerabilities"

# インライン版（v2.1.205+）との違い
claude --append-subagent-system-prompt "Always respond in Japanese." \
  -p "analyze this code"
```

**用途:** CI/CD で組織の長大なセキュリティポリシー・コンプライアンス要件をファイルで管理し、サブエージェントに一括適用する場合に有効。

---

### 3. 停止状態からのサブエージェント再開（v2.1.261+）

`TaskStop` で明示的に停止したサブエージェントも `SendMessage` で再開できるように。

**再開可能条件（更新）:**
- ✅ 完了状態のサブエージェント（従来から対応）
- ✅ 実行中のサブエージェント（v2.1.191+ から対応）
- ✅ **`TaskStop` で停止したサブエージェント（v2.1.261+ 新対応）**
- ❌ `x` キーで手動削除したサブエージェント

---

### 4. `permissionDecision: "skip"` 第3オプション（新規確認）

フックの権限決定フィールド `permissionDecision` に `"skip"` が追加されていることを今週初確認。

```json
{
  "hookSpecificOutput": {
    "permissionDecision": "skip",
    "permissionDecisionReason": "環境変数が未設定のため今回はスキップ"
  }
}
```

| 値 | 動作 |
|----|------|
| `"allow"` | ツール呼び出しを許可 |
| `"deny"` | ツール呼び出しをブロック |
| `"skip"` | **（今週確認）** 現在の処理をスキップ（次のフックへ） |

`PreToolUse`, `PostToolUse`, `PostToolUseFailure`, `PermissionRequest`, `PermissionDenied` のフック出力として使用可能。

---

### 5. `statusMessage` フックフィールド（公式確認）

フック実行中にスピナーのメッセージを上書きできる `statusMessage` フィールドが公式ドキュメントで明記された。

```json
{
  "type": "command",
  "command": "long-security-scan.sh",
  "statusMessage": "セキュリティスキャン実行中...",
  "timeout": 120
}
```

フック実行中に Claude Code のステータスバーに表示されるテキストをカスタマイズできる。デバッグ時やユーザー体験の向上に有効。

---

### 6. `disableAllHooks: false` でユーザー設定をオーバーライド（公式確認）

プロジェクト設定の `disableAllHooks: false` が、ユーザー設定の `disableAllHooks: true` を上書きすることが公式ドキュメントで明確化された。

```json
// ~/.claude/settings.json（ユーザー設定）
{ "disableAllHooks": true }

// .claude/settings.json（プロジェクト設定）
{ "disableAllHooks": false }  // ← ユーザー設定の true を上書き
```

**制限:** マネージドポリシーのフックはいずれの設定でも無効化不可。

---

### 7. `claudeMdExcludes` symlink 両パス対応（v2.1.239+）

`claudeMdExcludes` でシンボリックリンクを通じてロードされるルールファイルを除外する際、v2.1.239+ からリンク元・リンク先のどちらのパスでもマッチするように改善された。

```json
{
  "claudeMdExcludes": [
    // v2.1.239+ では以下のどちらでもマッチ可能
    ".claude/rules/shared/security.md",      // リンク元パス
    "/home/user/shared-rules/security.md"    // リンク先パス
  ]
}
```

v2.1.239 以前はリンク先のパスでのみマッチしていた（リンク元パスでマッチ不可）。
