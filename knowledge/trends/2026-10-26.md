## 今週のホットトピック

### 1. フォークモードが全モードでデフォルトON（v2.1.302）

`CLAUDE_CODE_FORK_SUBAGENT` がインタラクティブモード限定（v2.1.232+）から全モードに拡大し、v2.1.302 でデフォルト ON となった。オフにするには `CLAUDE_CODE_FORK_SUBAGENT=0` を明示的に設定する必要がある。

フォークモードとはサブエージェントが親会話の全コンテキストを継承して起動するモードで、デフォルト化により明示的な `subagent_type: "fork"` 指定なしでもフォーク挙動が採用されるケースが増える可能性がある。

### 2. サブエージェント名のセッション再起動後保持（v2.1.299）

v2.1.299 より、サブエージェントに付けた名前（`name` フロントマターフィールド）がセッション再起動後も保持されるようになった。これにより `SendMessage` での継続連絡が再起動後でも確実になる。

### 3. フックスキルソース上限の大幅拡張（v2.1.304）

1スキルソースあたりのフック定義上限が **1,024件** に拡張された（v2.1.304+）。複雑なフック体系を持つ組織や、大規模プラグインを開発するケースでスケール制約が大幅に緩和された。

### 4. `CLAUDE_CODE_DISABLE_FILE_MENTIONS` 環境変数（v2.1.299）

この環境変数を設定すると、PreToolUse フックが `@` 参照によるファイル読み込みを検知できるようになる。通常、`@` 参照はフックのツール呼び出し検知より前に処理されるため、フックでの可視性がなかった。この環境変数によりセキュリティフックでの `@` 参照監視が可能になる。

### 5. MCP ツール向けフック入力の強化（v2.1.274）

PreToolUse / PostToolUse のイベント入力に `mcp_server` オブジェクトが追加された。このオブジェクトには以下のフィールドが含まれる：
- `server_name`: MCP サーバー名
- `server_label`: 表示用ラベル
- `transport`: 通信方式

プラグインバンドルの MCP サーバーでは、`server` 値が `plugin:<plugin-name>:<server-name>` 形式になる。

## フックイベント・入力フィールドの詳細補完

### PostToolUse の新フィールド
- **`classifierContext`（v2.1.236+）**: Auto Mode 分類器がツール呼び出しをどう判定したかのコンテキスト情報。PostToolUse で取得可能。
- **`bashEditDiff`（v2.1.269+）**: Bash ツールの `tool_response` に含まれる差分情報。`Edit` を実行した Bash コマンドの変更内容をフック側で確認できる。
- **`mcp_server` オブジェクト（v2.1.274+）**: MCP ツール呼び出し時に PreToolUse / PostToolUse 入力に追加されるオブジェクト。サーバー名・ラベル・トランスポート方式を含む。

### `-p` モードのフック挙動
- **`stop_reason: "tool_deferred"`（v2.1.246+）**: `permissionDecision: "defer"` を返したフックがある場合、`-p`（非インタラクティブ）実行では defer された理由を `stop_reason` フィールドで確認できる。
