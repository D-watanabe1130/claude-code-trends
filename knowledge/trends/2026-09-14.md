## 今週のホットトピック（前週比差分）

### 1. v2.1.267+ 確認・`bypassPermissions` サブエージェントモード追加

サブエージェントの `permissionMode` に新たに `bypassPermissions` が追加された。ただし、**メインセッション自体が `bypassPermissions` モードで動作している場合のみ有効**。誤って組織ポリシーを回避できないよう、メインの権限レベルに依存する設計になっている。

```yaml
---
name: unrestricted-agent
permissionMode: bypassPermissions   # メインが bypassPermissions の場合のみ有効（v2.1.267+）
---
```

### 2. v2.1.251+: モデル解決順序が変更（重要・破壊的変更）

v2.1.248 から v2.1.257 の間に発生した重要変更。`CLAUDE_CODE_SUBAGENT_MODEL` 環境変数の優先度が**第1位→第3位**に降格した。

**v2.1.251+ 以降の解決順序:**

| 優先順位 | ソース |
|---------|------|
| 1（最高） | 呼び出し時の `model` パラメータ |
| 2 | フロントマターの `model` フィールド |
| 3 | `CLAUDE_CODE_SUBAGENT_MODEL` 環境変数 |
| 4 | メイン会話のモデル |

**v2.1.251 以前:** `CLAUDE_CODE_SUBAGENT_MODEL` が最高優先度だった。

この変更が v2.1.257+ で `CLAUDE_CODE_SUBAGENT_MODEL_FORCE=1` が導入された理由。Force フラグで旧来の「env が全フロントマターを上書きする」挙動を取り戻す。

### 3. v2.1.257+: フック共通入力に `scratchpad_dir` フィールド追加

全フックイベントの共通入力に `scratchpad_dir`（セッションのスクラッチパッドディレクトリパス）が追加された。一時ファイルを扱うフックスクリプトで利用できる。

```bash
#!/bin/bash
INPUT=$(cat)
SCRATCHPAD=$(echo "$INPUT" | jq -r '.scratchpad_dir')
# フック内で一時ファイルを scratchpad_dir に保存
echo "$INPUT" > "$SCRATCHPAD/hook-debug.json"
```

### 4. `cloud_credential_error` StopFailure マッチャー追加（v2.1.267+）

クラウド認証エラーを StopFailure フックでキャッチできるようになった。

```json
{
  "hooks": {
    "StopFailure": [
      {
        "matcher": "cloud_credential_error",
        "hooks": [{ "type": "command", "command": "refresh-cloud-credentials.sh" }]
      }
    ]
  }
}
```

### 5. `Notification` マッチャーが大幅拡充（7種追加）

前週確認の `elicitation_dialog`・`quota_auto_resume_fired` に加え、今週さらに7種が確認された:

**新規確認:**
- `elicitation_url_dialog` – URLを要求するElicitation
- `elicitation_complete` – Elicitation処理完了
- `elicitation_response` – Elicitation応答後
- `agent_needs_input` – エージェントがユーザー入力を必要とする
- `agent_completed` – エージェントが完了
- `quota_auto_resume_stale` – クォータ自動再開が古い
- `quota_auto_resume_disabled` – クォータ自動再開が無効

### 6. `StopFailure` マッチャーが大幅拡充（7種追加）

前週確認の `rate_limit`・`overloaded`・`authentication_failed` に加え、今週さらに7種が確認された:

**新規確認:**
- `oauth_org_not_allowed` – OAuth 組織未許可
- `account_on_hold` – アカウント保留中
- `billing_error` – 請求エラー
- `invalid_request` – 不正なリクエスト
- `model_not_found` – モデルが見つからない
- `server_error` – サーバーエラー
- `max_output_tokens` – 出力トークン上限超過

### 7. `v2.1.242+`: `/tasks` コマンドがモデルとエフォートレベルを表示

`/tasks` コマンドで実行中・完了済みサブエージェントの一覧に**モデル名**と**エフォートレベル**が追加された（v2.1.242+）。コスト管理・デバッグに有用。

### 8. `v2.1.233+`: `claude plugin validate <path>` コマンド追加

プラグインのエージェントフロントマターを静的検証するコマンド。CI/CDパイプラインでの事前チェックに活用できる。

```bash
claude plugin validate .claude/plugins/my-plugin/
```

### 9. `Setup` フックイベントのマッチャー詳細確認

`Setup` イベントには `init` または `maintenance` のマッチャーが使える。`--init-only`・`--init` フラグ使用時に `init` が、`--maintenance` 使用時に `maintenance` がマッチする。

```json
{
  "hooks": {
    "Setup": [
      {
        "matcher": "init",
        "hooks": [{ "type": "command", "command": "project-init.sh" }]
      },
      {
        "matcher": "maintenance",
        "hooks": [{ "type": "command", "command": "maintenance-tasks.sh" }]
      }
    ]
  }
}
```

### 10. `allowManagedHooksOnly` の詳細確認

組織管理者向けの設定で、以下を制限する:
- **ブロック対象**: user/project/local 設定のフック・force 有効でないプラグインフック
- **スコープ縮小**: `statusLine`・`fileSuggestion`・`subagentStatusLine` をマネージド設定のみに制限
- **無効化**: コマンドソースプラグイン（`disableCommandPluginSources: false` で例外）
- **ブロック**: マーケットプレイスの `headersHelper` コマンド（同上の例外あり）
