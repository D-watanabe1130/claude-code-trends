## 補完確認：未記録フックイベント4種の詳細判明

前回レポートで「総33種」と記録していたフックイベントのうち、以下4種の詳細が今週のドキュメント取得で確認された。機能自体は既存だが、KB への明示記録がなかったため補完する。

### `MessageDisplay`

- **カテゴリ**: Display and notifications
- **発火タイミング**: アシスタントテキストのストリーミング中（ターンごとに複数回発火）
- **タイムアウト**: 10秒（他のほとんどのフックより短い）
- **特徴**: `hookSpecificOutput.displayContent` を返すと、画面に表示される内容のみを変更できる。**トランスクリプトおよび Claude が実際に見るテキストは変わらない**
- **主なユースケース**: Markdown のボールド記号を除去した表示、機密情報のマスク表示など

```json
{
  "hookSpecificOutput": {
    "hookEventName": "MessageDisplay",
    "displayContent": "プレーンテキスト（強調記号なし）"
  }
}
```

### `PostToolBatch`

- **カテゴリ**: Tool loop
- **発火タイミング**: 1バッチのツール呼び出しが全て完了した後、次のモデルリクエストの前に1回
- **特徴**: 並列ツール呼び出しをまとめて検証する際に有効。`additionalContext` フィールドに対応
- **主なユースケース**: 並列編集後の一括整合性チェック、バッチ完了後のログ記録

### `WorktreeCreate`

- **カテゴリ**: Environment
- **発火タイミング**: `isolation: worktree` のワークツリー作成時
- **特徴**: HTTP フックは `hookSpecificOutput.worktreePath` でカスタムパスを返せる。非ゼロ終了はワークツリー作成失敗として扱われる
- **主なユースケース**: ワークツリーに動的なパス名を割り当てる

### `WorktreeRemove`

- **カテゴリ**: Environment
- **発火タイミング**: ワークツリー削除時
- **主なユースケース**: ワークツリー削除後のクリーンアップ処理

## 補完確認：未記録ツール入力フィールド

### v2.1.282: WebSearch `mode` パラメーター

WebSearch ツールの呼び出し入力に `mode` フィールドが追加されていた。`"standard"`（デフォルト、高速・低コスト）と `"extended"`（詳細・高コスト）の2値。フックで WebSearch を監視している場合、`tool_input.mode` で実行モードを判別できる。

### v2.1.290: WebFetch `offset` 入力フィールド / TaskCreated `agent_id` フィールド

- **WebFetch `offset`**: WebFetch ツール呼び出しに `offset` 入力フィールドが追加。ページの途中から読み取る際に使用される文字位置。フックでの WebFetch 監視で参照可能
- **TaskCreated `agent_id`**: TaskCreated フックイベントの入力に `agent_id` フィールドが追加。どのサブエージェントがタスクを作成したかをフックで追跡できる

## ベストプラクティスドキュメントの新規確認事項

### "be ambitious" プロンプト技法

公式ベストプラクティスドキュメントに `"be ambitious"` フレーズが推奨プロンプト技法として明記された。Claude は要求を保守的に解釈して最小限の実装を返す傾向があるため、エッジケース処理・自然な後続実装・フル機能版を望む場合はこのフレーズで明示的に指定できる。

```
設定ページをモックアップから実装してください。be ambitious: 空・エラー状態、保存フローの配線、キーボードナビゲーション、レイアウトだけでなく。
```

これはエフォートレベル（thinking の深さ）の制御ではなく、スコープ（どこまで実装するか）の指示であることが明記されている。

### スペースを含むパスのインポート記法

CLAUDE.md でスペースを含むパスを `@` インポートする場合、スペースの前にバックスラッシュが必要。

```text
# 正しい
- API 規約 @Design\ Docs/api-conventions.md

# 誤り（スペースで切れる）
- API 規約 @Design Docs/api-conventions.md

# 誤り（インポートされない）
- API 規約 "@Design Docs/api-conventions.md"
```

### Cowork セッションの外部インポート制限

デスクトップ上の Cowork セッションでは、user-scope ファイル（`~/.claude/CLAUDE.md` 等）内のインポートのうち、セッションの working directory 外に解決されるものはスキップされる。また `~/.claude/CLAUDE.md` 自体がシンボリックリンクまたはハードリンクの場合もスキップされる。Cowork セッション外の通常動作は変わらない。
