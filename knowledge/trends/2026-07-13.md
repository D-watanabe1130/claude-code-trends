## 今週のホットトピック（前回差分）

### 1. `/doctor` コマンド（v2.1.205+）★最重要

重複したサブエージェントファイルを自動検出・報告する新コマンド。同一 `.claude/agents/` ディレクトリ内で同じ `name` を持つファイルが存在する場合、リネームまたは削除の提案を行う。

```bash
/doctor  # 設定の健全性チェック（重複エージェント名など）
```

v2.1.205 以前は `/doctor` が diagnostics 画面を表示して重複を一覧表示していたが、v2.1.205+ では自動解決提案が追加された。

### 2. `--append-subagent-system-prompt` フラグ（v2.1.205+）

非インタラクティブモードで全サブエージェント（ネストを含む）のシステムプロンプト末尾に追加テキストを注入できる。

```bash
claude --append-subagent-system-prompt "Always respond in Japanese." -p "..."
```

スクリプト・自動化シナリオで全サブエージェントの動作を一括制御できる。

### 3. Explore サブエージェントのモデル継承変更（v2.1.198+）

**変更前**: Explore は常に Haiku モデルで動作
**変更後**: Explore はメイン会話のモデルを継承（Claude API では Opus を上限としてキャップ）

- Bedrock / Vertex / Foundry など他プロバイダーでは上限なしで継承
- Haiku 固定を維持したい場合は `~/.claude/agents/Explore.md` に `model: haiku` を設定して組み込みを上書き

```markdown
---
name: Explore
description: Fast read-only search agent
model: haiku
---
```

### 4. `background` フィールドとデフォルト動作の変更（v2.1.198+）

サブエージェントフロントマターに `background` フィールドが追加され、v2.1.198 以降はデフォルトでバックグラウンド実行に変更された。

```yaml
---
name: my-agent
description: ...
background: true  # 明示的指定（結果が不要な時でも常にバックグラウンド）
# background: false でフォアグラウンド強制
---
```

| 値 | 挙動 |
|---|---|
| `true` | 常にバックグラウンドタスクとして実行 |
| 未設定 | v2.1.198+ ではデフォルトでバックグラウンド（以前はフォアグラウンド） |

### 5. `permissionMode: "manual"` エイリアス（v2.1.200+）

サブエージェントの `permissionMode` フィールドに `"manual"` が `"default"` のエイリアスとして追加。

```yaml
permissionMode: manual  # "default" と同義（v2.1.200+）
```

人間が読みやすい名前で「デフォルト（手動承認）モード」を明示できる。

### 6. `/agents` コマンドのウィザード廃止（v2.1.198+）

`/agents` コマンドがインタラクティブ作成ウィザードを廃止し、`.claude/agents/` を直接編集するか Claude に作成を依頼するよう案内するメッセージを表示するのみになった。

- サブエージェントファイル自体の形式・配置場所・フロントマター仕様は変更なし
- ファイル変更の即時検出（数秒以内）は継続（例外: セッション開始後に新規 `agents/` ディレクトリを作成した場合）

### 7. `isolation: worktree` のバグ修正（v2.1.203+）

`isolation: worktree` を設定したサブエージェントで、ワークツリーディレクトリが削除された場合に誤ってメインチェックアウトで Bash コマンドが実行されるバグを修正。

**v2.1.203+ の動作**: ワークツリーが削除された状態でのコマンド実行はエラーで失敗する（サイレントにメインチェックアウトへ fallback しない）。

### 8. ネストディレクトリでの同名エージェント優先ルール（v2.1.178+）

複数の `.claude/agents/` ディレクトリに同じ `name` のサブエージェントが存在する場合、**カレントワーキングディレクトリに最も近い定義が優先**される。

```
/repo/.claude/agents/reviewer.md   # 優先度低
/repo/src/.claude/agents/reviewer.md  # cwd が /repo/src の場合こちらが優先
```

### 9. フック出力の文字数制限詳細

フック出力文字列に 10,000 文字の上限が明文化された。超過した場合はファイルに保存され、プレビュー＋パスが表示される。以下が対象:
- `additionalContext`
- `systemMessage`
- コマンドの stdout（plain text）

### 10. `PermissionDenied` フックの `retry: true` パターン

Auto Mode 分類モデルがツール呼び出しを拒否した際に発火する `PermissionDenied` フックで、`retry: true` を返すと操作を再試行させることができる。

```json
{
  "hookSpecificOutput": {
    "hookEventName": "PermissionDenied",
    "retry": true
  }
}
```
