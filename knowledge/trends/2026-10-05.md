## 前回（2026-09-28）との差分

### 1. v2.1.286+: バックグラウンドエージェントへのキーボードショートカット（NEW）

サブエージェントドキュメントに以下のキーボードショートカットが明記された。

| ショートカット | 機能 |
|------------|------|
| `Ctrl+Enter` | 現在閲覧中のエージェントにメッセージを送信 |
| `Ctrl+X Ctrl+S` | 現在閲覧中のエージェントにメッセージを送信（代替） |

バックグラウンドで実行中のサブエージェントをタスクリストで選択して閲覧している状態で、メインセッションを切り替えることなく直接指示を送れるようになった。

### 2. v2.1.251+（補完）: 再開時 SessionStart フックの新規入力フィールド

フックドキュメントに明記されていたが前回報告で見落とされた情報。セッション再開（`resume`）時の `SessionStart` フックに以下の追加フィールドが注入される（v2.1.251+）：

| フィールド | 内容 |
|-----------|------|
| `seconds_since_last_response` | 前回レスポンスからの経過秒数 |
| `context_tokens` | セッション再開時のコンテキストトークン数 |
| `prompt_cache_likely_expired` | プロンプトキャッシュ有効性の推定（bool） |
| `estimated_cache_write_usd` | キャッシュ書き込みの推定コスト（USD） |

活用ユースケース：
- `prompt_cache_likely_expired` が `true` の場合は `/compact` でコンテキストを圧縮してからタスク再開
- `context_tokens` で再開コストを推定して長期セッションの戦略を調整
- `estimated_cache_write_usd` でコスト監視

## 設計パターンへの示唆

### 再開時コスト監視フックパターン（v2.1.251+）

```bash
#!/bin/bash
# SessionStart (resume) フックで再開コストを推定・ログ出力
INPUT=$(cat)
SOURCE=$(echo "$INPUT" | jq -r '.hookSpecificOutput.sessionStartSource // "unknown"')

if [ "$SOURCE" = "resume" ]; then
  CACHE_EXPIRED=$(echo "$INPUT" | jq -r '.prompt_cache_likely_expired // false')
  CTX_TOKENS=$(echo "$INPUT" | jq -r '.context_tokens // 0')
  EST_COST=$(echo "$INPUT" | jq -r '.estimated_cache_write_usd // 0')
  
  if [ "$CACHE_EXPIRED" = "true" ]; then
    # キャッシュ期限切れの場合は圧縮推奨メッセージを返す
    jq -n '{
      hookSpecificOutput: {
        hookEventName: "SessionStart",
        additionalContext: "プロンプトキャッシュが期限切れの可能性があります。\n/compact でコンテキストを圧縮してから再開することを推奨します。"
      }
    }'
  fi
fi
```

### エージェントへのキーボードメッセージ送信の活用場面

- バックグラウンドで調査中のエージェントに「この方向で続けてください」と追加指示
- 並列実行中の複数エージェントを順に切り替えて進捗確認・軌道修正
- フォアグラウンドセッションを止めずにバックグラウンドエージェントを誘導
